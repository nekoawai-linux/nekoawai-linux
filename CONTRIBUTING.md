The artists behind the pictures on a desktop are not on this list, and not
because they are owed less. `nekowall` fetches from public galleries, so the
list changes with every wallpaper: it credits whoever drew the one on screen
beside the picture itself, and `nekowall --current` prints the name and links
back to the original.
